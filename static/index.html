Six steganography channels

Image
Web + CLI
PNG · BMP

LSB-encodes payload bits into the least significant bit of each RGB channel value. 1 bit per channel, invisible to the eye at any zoom level.

Capacity: ~37 KB per megapixel
Audio
Web + CLI
WAV · FLAC · AIFF · MP3

LSB-encodes into 16-bit PCM audio samples. MP3 input is accepted and decoded to PCM first. Output is always lossless WAV — MP3 compression would destroy hidden bits.

Capacity: ~330 KB per 30s stereo WAV
QR Code
Web + CLI
PNG (ECC H level)

Generate a real, scannable QR for any URL, then embed a secret in the PNG pixel LSBs. QR ECC H level tolerates 30% module damage — sub-pixel LSB flips are far below that threshold, so the QR remains fully scannable.

Capacity: Varies by QR scale (10px default)
Text
Web + CLI
Any Unicode text

Encodes payload bits as invisible zero-width Unicode characters (U+200B, U+200C, U+200D) inserted between visible characters. Renders invisibly in Discord, Slack, email, and browsers.

Capacity: Unlimited (1 bit per visible char)
PDF
Web + CLI
PDF

Two techniques: (1) invisible font-size-0 text layer appended to new or existing PDFs, (2) base64 payload injected into /Keywords metadata of existing PDFs. Both pass casual document inspection.

Capacity: Unlimited
Git
CLI only
Any git repository

Two channels: (1) timestamp — encodes 6 bits per commit via author timestamp seconds % 64, (2) whitespace — trailing whitespace patterns in commit message bodies. Survives git clone and push.

Capacity: Unlimited (scales with commit count)
01

Encrypt payload

Your secret message is encrypted with AES-256-GCM. PBKDF2-HMAC-SHA256 (600,000 iterations) derives the 256-bit key from your password. Without the key, extracted bits are indistinguishable from noise.

02

Embed in carrier

The encrypted bytes are written as LSB bits across millions of image pixels, audio samples, or Unicode positions — changes too small to perceive visually or aurally. The carrier file remains fully functional.

03

Extract anywhere

Share the carrier file over any channel. The receiver loads it into Invisync, provides the password, and the original plaintext is recovered — authenticated by GCM tag so any tampering is detected.
